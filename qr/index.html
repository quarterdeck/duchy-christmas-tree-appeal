Before you order glitter stickers

  • The red ring is for glitter. Keep the white circle and the QR code solid white and black, with no glitter. Glitter behind the code lowers the contrast and phones can fail to scan it.
  • Ask Sticker Mule for a proof. Scan the proof with an iPhone and an Android phone before you approve it.
  • Do not make the sticker smaller than 2 in (51 mm).
  • The QR code uses the highest error correction (level H), so the small tree in the centre does not stop it from scanning. A long website address makes a denser code with no tree.
  • Test a paper print at the real size first.
